Auto-create or verify all Google Sheet tabs and headers
What this does

Running setup will check your Google Sheet and:

  • Create any missing tabs
  • Fix headers on tabs that exist but are wrong or blank
  • Leave tabs that are already correct untouched
  • Never deletes any existing data rows
⚠️ Run setup after any schema update

After adding voucher_name/voucher_value/card_value columns and the ordered_by column in secondary_orders, run setup once to update the sheet headers. Your existing data rows are never deleted — new columns will simply be blank for old orders.

Next steps after setup
1. Share your sheet
Make sure your Google Sheet is shared as Editor with the client_email from your service account JSON.
2. Add Vouchers in Settings
Go to Settings → Vouchers to add voucher types and values (e.g. HDFC Gift Card ₹6000).
3. Add Ordered By Names
Go to Settings → Ordered By Names to add the names used in Secondary Orders. This field is optional — leave blank when not needed.
4. Add other master data
Add your cards, platforms, models, variants, machines, vendors, and brands.
5. Start adding orders
Main Orders and Secondary Orders both support voucher deductions now. Secondary Orders also has the new Ordered By + Order Name fields.
6. Check the Dashboard
Dashboard shows your profit analytics across all channels.
